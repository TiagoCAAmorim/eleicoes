# Histórico da apuração de 2026

Protocolo usado na noite de 25/10/2026: um agente na nuvem corrigia o código e escrevia pedidos numerados
(`agentes/pedidos.md`); um agente local no computador do Tiago rodava o loop e respondia. Os caminhos citados
nesses arquivos são os do repositório antigo (`misc/eleicao-presidencial`): `run.py` virou `scripts/apuracao.py`,
`eleicao/` virou o pacote `eleicoes/`, `data/` virou `dados/` e `saida/2026` virou `resultados/2026-presidente`.
